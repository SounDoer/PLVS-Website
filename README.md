# PLVS Website

The source for the public [PLVS website](https://plvs.soundoer.com/). This repository owns
site templates, navigation, styles, published image assets, and HTML rendering. The
[PLVS product repository](https://github.com/SounDoer/PLVS) owns the user guide, reviewed
privacy policy, and Sharesets validation and compatibility rules.

## Build a candidate

Use Node from `.nvmrc` and run `npm ci`. Generate a website input bundle with
`scripts/export-website-inputs.mjs` in a PLVS checkout. The exporter takes clean checkouts
at the chosen product, Catalogue, and privacy revisions. For example, from PLVS:

```sh
node scripts/export-website-inputs.mjs <stable-checkout> <new-input-directory>
```

In this repository, run:

```sh
npm run check -- <input-directory>
```

The result is a complete static site in `artifacts/website/`. The input manifest records
the source commits. The site reads the exported guide, reviewed policy body, Catalogue
presentation data, and validated assets. The build itself can run with only the bundle
and this checkout.

CI exports inputs from its pinned PLVS reference and uploads a reviewable candidate.

Use the Catalogue bundle generated by PLVS curation as an optional review overlay:

```sh
npm run build -- <stable-inputs> artifacts/catalogue-review <review-directory>/site-inputs
python -m http.server 4173 --bind 127.0.0.1 --directory artifacts/catalogue-review
```

The production workflow builds only from its resolved publication inputs. The homepage image
tools in PLVS write reviewed assets into this checkout. Source PNGs and provenance under
`website/assets/raw/` are kept for reproducibility and excluded from published output.
See [DESIGN.md](DESIGN.md) for presentation rules.

## Publish

Review the candidate against the live website and wait for successful push CI on its exact SHA.
Use the shared Pages workflow in PLVS to deploy to the existing domain:

```sh
gh workflow run deploy-website.yml --repo SounDoer/PLVS --ref main -f ref=v<stable> -f website_ref=<website-sha>
```

The stable product selection pins both the guide and the homepage downloads. The workflow
keeps the live Catalogue and privacy revisions for website-only changes by default, checks
immutable Catalogue history, and records all source commits in the live publication marker.
See the [PLVS publication guide](https://github.com/SounDoer/PLVS/blob/main/docs/website-and-sharesets.md#website-checks-and-independent-publication)
for privacy review, version changes, and verification.
